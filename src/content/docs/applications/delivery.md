How do users actually fill out your application? You can configure this under **Edit Application > General Settings**.

![Delivery Methods Selector](/images/applications/delivery_methods.png)

## Application Methods

| Method | Description |
| :--- | :--- |
| **Direct Message (DM)** | The bot sends the form to the user's DMs. (Requires users to have server DMs enabled). |
| **Web Portal** | Generates a secure web link (e.g., `ticketforge.xyz/apply/...`) that users can fill out in their browser. |
| **Both** | Allows the user to choose their preferred method when they click the trigger button in your server. |

## Web Portal Features

If you use the Web Portal method, you gain access to several powerful tools tailored for browser-based submissions:

* **Require Discord Sign-in:** *(Premium)* Forces users to log in with Discord before viewing the form, preventing link forwarding to non-members.
* **Allow Anonymous Submissions:** *(Premium)* Collect raw feedback without attaching a Discord account identity. (Anonymous submissions cannot be formally "Accepted" or "Denied" as there is no user to notify).
