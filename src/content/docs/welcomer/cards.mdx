## 2. Custom Drag & Drop Canvas

<Badge text="Premium" variant="caution" />

When **Custom** layout is selected, an interactive canvas appears directly in the dashboard:

![Custom Layout Drag & Drop Canvas](/images/welcomer/layout_custom.png)

* **Bounded Drag & Drop:** Click and drag any element directly on the card preview. Coordinates are automatically bounded to prevent avatars or text from clipping off the edges.
* **Reset Layout:** One-click reset restores default coordinates, sizes, and `#FFFFFF` text colors.

### Customizable Elements

Each element can be individually **toggled ON/OFF**, resized, recolored (hex picker), and repositioned:

| Element | Controls Available | Notes |
| :--- | :--- | :--- |
| **Avatar** | Toggle, Size (`40px` – `140px`), X/Y Position | Rendered as a circle with an outer border matching the Name color. |
| **Header Text** | Toggle, Font Size (`8px` – `24px`), Color, X/Y Position | Automatically localized to your server's **Bot Language** (e.g., *"Welcome to the server"*). |
| **Name (Title)** | Toggle, Font Size (`12px` – `40px`), Color, X/Y Position | Displays the joining member's display name / username. |
| **Subtitle** | Toggle, Font Size (`9px` – `26px`), Color, X/Y Position | Displays `Member #<count>`. |
| **Milestone Badge** | X/Y Position | Appears on the canvas when customizing an independent Milestone Card. |

![Background Theme Gallery & Dim Opacity](/images/welcomer/card_themes.png)

* **Transparent:** Outputs a clean transparent PNG background (ideal for minimalist overlays).

### Custom Background Uploads <Badge text="Premium" variant="caution" />
Select **Upload your own** and paste a direct `http://` or `https://` image URL (PNG or JPG—supports Discord CDN, Imgur, and S3 URLs).
* **Recommended Resolution:** `1024×450px` (automatically center-cropped to cover if aspect ratio differs).

### Background Dim Opacity
Use the **Background Dim Opacity** slider (`0%` to `100%`, default `10%`) to add a dark overlay behind your text and avatar, ensuring high contrast on bright or detailed backgrounds.

:::note[Automatic Emoji & Unicode Support]
Welcome cards bundle **Inter** and **Noto Color Emoji** fonts natively, ensuring Unicode usernames and milestone badge emojis render accurately.
:::
